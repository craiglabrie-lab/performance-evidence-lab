# ADR-0005 — The Devil's Advocate reads the evidence first

**Decision:** The Devil's Advocate runs twice. The first call sees only the scenario, the fact sheet and the evidence register, and writes its own view. The second call reads the team's conclusions and challenges them. The Test Lead must rule on every objection.

**Why:** A reviewer who reads the conclusion first tends to check whether it is plausible, not whether it is right. Forming an independent view first, then comparing, is how good human reviews avoid anchoring.

**Limits:** All agents run on the same model. The Devil's Advocate has a separate context, not a separate mind. Reports say so.

**Revisit when:** a different model is available for the challenge role, and runs can measure whether it finds more.
