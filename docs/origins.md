# Origins

Performance Evidence Lab grew out of seventeen years of reviewing load-test results, most recently as the lead of a performance testing team, where every scenario, result set and report passed through one review discipline before it reached a release decision.

The first written form of that discipline was a single, long AI prompt for analysing OpenText LoadRunner Enterprise results ("V2"). It introduced run isolation, inventory before retrieval, a mandatory workload-validity check, time normalisation, phase-aware correlation, evidence grading and final report QA. This project keeps those ideas and splits them across a team, so each one has an owner and can be checked.

The architecture borrows from a sibling project, [Hive & Seek](https://github.com/craiglabrie-lab/hive-and-seek), which applies the same pattern — specialist agents, shared evidence, an independent challenger and explicit decision records — to job searching.

References to LoadRunner, OpenText or other products describe where the ideas came from. They do not imply endorsement, and no vendor material is included.
